# Chess Club at CSUSB – Website

Official website of the Chess Club at CSUSB (Coyote Chess Club).
Live site: https://coyotechessclub.org

## About the project
Built by Group 7 for the Web Technologies course at California State
University, San Bernardino. Students can learn about the club, see
upcoming events and news, play online and request membership.

- PHP 8 and MySQL (course version with admin panel)
- GitHub Pages (live hosting)
- Chess.com Published-Data API
